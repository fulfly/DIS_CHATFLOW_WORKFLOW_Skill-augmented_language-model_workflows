# Raw Data Folder

Place the real CSV or Excel input tables here before running the scripts.

Default filenames expected by the scripts:

- `fig3_model_runs.csv`
- `fig3_pairwise_similarity.csv` optional if `fig3_model_runs.csv` contains `output_text`
- `fig4_viscosity_timecourse.csv`
- `fig5a_formulation_ratios.csv`
- `fig5b_release_uv.csv`
- `fig5b_file_mapping.csv` for the Excel-based Fig. 5b UV workflow

For the Excel-based Fig. 5b UV workflow, place `.xlsx`, `.xls`, or `.xlsm` files in:

- `fig5b_uv_excel/`

Header-only templates are available in `../data_templates/`.
