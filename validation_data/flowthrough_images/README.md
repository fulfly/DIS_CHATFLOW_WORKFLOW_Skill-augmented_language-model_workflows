# Flow-Through Image Samples

This folder contains representative sampled images from methylene-blue sustained-release tablet flow-through disintegration experiments.

## Public Sample Scope

- Three formulation conditions: low-viscosity, standard-viscosity, and high-viscosity methylene-blue sustained-release tablets.
- Five sampled frames per formulation.
- Stable English filenames containing formulation condition and frame time label.
- `sample_manifest.csv` records the sampling map.

These files are representative validation images only. They are provided to show image format and visual evidence examples, not to replace the complete confidential image/video dataset.
