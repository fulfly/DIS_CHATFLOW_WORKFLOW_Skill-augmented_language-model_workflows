# Flow-Through Image Samples

This folder contains representative sampled images from the methylene-blue sustained-release tablet flow-through disintegration experiment.

The public repository includes sampled validation images only. The complete image/video dataset is excluded for confidentiality and size control.

Sampling rule used for this staging package:

- three formulations: low-viscosity, standard-viscosity, and high-viscosity methylene-blue sustained-release tablets
- five sampled frames per formulation
- stable English filenames with the formulation condition and frame time label

These images are intended for inspection of data format and representative visual evidence. They should not be treated as the full validation dataset.
