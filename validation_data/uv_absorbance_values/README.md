# UV Absorbance Values

This directory contains public-safe UV absorbance validation records for sustained-release formulation evaluation.

## Included Records

- `methylene_blue_uv_absorbance*.xlsx`: methylene-blue UV validation spreadsheets copied from reviewed source records.
- `gliclazide_uv_absorbance_*.xlsx`: gliclazide UV validation spreadsheets copied from the approved UV output folder.
- `fig5b_release_uv_*` and `fig5b_uv_qc.csv`: QC/template records related to Fig. 5b UV processing.

The expected final CSV exports can be generated from the real spreadsheets when needed. No synthetic UV values are included.
