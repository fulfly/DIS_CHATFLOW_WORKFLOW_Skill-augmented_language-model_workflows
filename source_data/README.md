# Source Data

This directory contains curated source data directly supporting manuscript figures and validation analyses.

## Included Scope

- Fig. 3 model-output metric source tables or source-equivalent CSV exports.
- Fig. 5 UV absorbance source tables or source-equivalent CSV/spreadsheet exports.
- Public-safe UV spreadsheet exports for methylene-blue release experiments where approved.

Chinese source filenames were copied under stable English filenames where needed. The complete private raw dataset is not included; see `repository_manifest.csv` for source-to-repository filename mapping.
