# Example Data

Small example images, Markdown outputs, conversation transcripts, and UV data intended to demonstrate the workflows without releasing full private or copyrighted datasets.

Added formulation-optimization conversation examples are organized under:
- `example_markdown_outputs/chatflow/`: Chatflow replicate outputs for gliclazide and methylene-blue formulation optimization.
- `example_markdown_outputs/gemini/`: Gemini formulation-optimization report outputs.

Large unreviewed image folders and skill-export folders remain outside this staged repository until explicitly approved.
