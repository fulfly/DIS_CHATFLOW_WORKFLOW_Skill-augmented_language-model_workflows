# Skills

This directory contains reusable skill modules used to translate workflow branches into auditable, file-based agent behaviors.

## Skill Modules

- `model_output_batch_analyzer/`: batch analysis of local model output files, coverage metrics, consistency summaries, and comparison reports.
- `ANON/`: background and formulation-context extraction for three-formulation optimization.
- `RANA/`: mechanistic interpretation and literature-supported reasoning for formulation variables and observed behavior.
- `SOYO/`: final formulation-optimization synthesis and recommendation logic.
- `TAKI/`: batch image-analysis support for disintegration image windows.

## Scope

Skill folders should contain reusable skill instructions, scripts, and supporting references. Model outputs or large dialogue exports should be kept in `example_data/` or `processed_data/` unless they are required as minimal examples.
