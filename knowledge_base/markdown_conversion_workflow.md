# Markdown Conversion Workflow

This note records the public, repository-safe description of the OCR/Markdown conversion workflow used during manuscript preparation. Full-text literature PDFs and converted full-text Markdown volumes are intentionally excluded from this repository.

Recommended public workflow summary:
1. Convert source documents with an OCR/Markdown toolchain in a private workspace.
2. Split or sanitize outputs only for local retrieval/indexing where licensing permits.
3. Export only derived, non-copyrighted summaries, metadata, prompts, scripts, and reproducibility notes to the public repository.
4. Keep raw PDFs, full-text converted Markdown, private logs, and large intermediate caches outside GitHub.

See `repository_manifest.csv` for files removed or skipped during staging review.
