# Knowledge Base

This directory contains public-safe documentation for retrieval and knowledge-base preparation steps used during manuscript development.

## Main Documents

- `openalex_query_and_filters.md`: human-readable summary of OpenAlex query terms, filters, and screening rules.
- `openfda_field_mapping.md`: OpenFDA/DailyMed field mapping for excipient and formulation knowledge extraction.
- `markdown_conversion_workflow.md`: repository-safe OCR/Markdown conversion workflow summary.

## Exclusions

Raw full-text papers, converted full-text literature Markdown, local database dumps, OCR caches, and private retrieval logs are intentionally excluded. Code snippets or local scripts are included only when they are public-safe and directly needed for reproducibility.
