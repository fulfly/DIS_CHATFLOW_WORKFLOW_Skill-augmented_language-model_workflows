# Mechanism Summary Generator

## Scope

Execute mechanism-level reasoning only. Do not produce A-versus-B final verdicts. Keep deterministic section assembly, size routing, assigners, and export in workflow.

Router mapping (fixed):
- Branch `5`: Mechanism analysis -> this skill
- Branch `4`: Two-drug comparison -> `comparison-verdict-generator`

## Inputs

- `image_analyses` (object or array, required, must match `../_contracts/image_analysis.schema.json`)
- `experiment_config` (object or JSON string, required)
- `retrieved_literature_context` (array of string, required, may be empty)
- `analysis_plan` (object/string, optional)

## Output Contract

- `mechanism_summary` must validate against `../_contracts/mechanism_summary.schema.json`
- Schema supports two branches via `oneOf`:
- `legacy_mechanism_summary_v1` (backward compatibility)
- `structured_mechanistic_v2` (target emission)
- `confidence` must remain in `[0,1]`
- `additionalProperties` must remain `false`

## Execution Rules

1. Pre-validate each `image_analyses` item structure:
- required keys: `group_id`, `time_h`, `eight_dimension_description`, `notes_for_later_summary`.
2. Build phenomenon summary from image timeline:
- Restate major observed patterns in one compact paragraph.
- Include at least two concrete phenomena from the eight dimensions.
3. Build literature-supported mechanism section:
- Use only provided `retrieved_literature_context`.
- Do not fabricate citation details.
- If evidence is sparse, explicitly state limitation.
4. Build reasoning chain explicitly:
- `Observed phenomena -> possible formulation/process factors -> possible release behaviour`
- Mark chain as hypothesis, not validated conclusion.
5. Build validation suggestions:
- Include at least two actionable checks (for example medium change, agitation change, comparative in-vitro study).
6. Populate v2 output fields:
- `phenomenon_review`
- `literature_supported_typical_mechanisms`
- `tentative_mechanistic_interpretation`
- `mechanism_chain`
- `suggestions_for_further_validation`
- `hypothesis_disclaimer`
- plus compatibility fields: `mechanism`, `drivers`, `counter_evidence`, `confidence`, `next_checks`
7. Calculate `confidence` deterministically:
- Start at `0.35`
- Add `0.20` if at least two coherent timeline phenomena are identified
- Add `0.20` if literature directly supports at least one mechanism link
- Add `0.10` if counter-evidence is explicitly documented
- Add `0.10` if interpretation references experiment conditions from `experiment_config`
- Subtract `0.20` if literature evidence is weak/indirect
- Clamp to `[0,1]`
8. Validate schema before return.
